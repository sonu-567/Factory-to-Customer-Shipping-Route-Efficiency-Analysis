# 🚚 Factory-to-Customer Shipping Route Efficiency Analysis

## 📌 Project Overview

This project analyzes shipping efficiency for **Nassau Candy Distributor** by evaluating factory-to-customer delivery routes.
The goal is to identify **delays, inefficiencies, and bottlenecks** in logistics operations using data analysis and visualization.

---

## 🎯 Objectives

* Analyze **shipping lead time** (Order Date → Ship Date)
* Identify **fastest and slowest routes**
* Compare **shipping performance across regions and states**
* Evaluate **ship mode efficiency (Standard vs Express)**
* Detect **frequent delays and bottlenecks**

---

## 📊 Key Features

* 📈 Lead Time Calculation
* 📍 Region-wise & State-wise Analysis
* 🚀 Ship Mode Comparison
* 📦 Delay Detection
* 📊 Multiple Visualizations using Matplotlib
